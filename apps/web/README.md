# Altas Panel web

Vite + React client for the v0.3.0-dev panel. Overview, Metrics, Analytics, and Stacks are signed-in routes.

```bash
npm install
npm run dev
```

The dev server listens on port 5173 and proxies `/api` to `http://127.0.0.1:8080`. The first account created against an empty database is the admin. After that, the register screen closes. See the repository README for the full local run.
